# App logo

`Keyboard Progress Key Icon.png` is the approved original artwork. A byte-for-byte
copy lives at `app/src/main/res/drawable-nodpi/app_logo.png` for Android resources.
When replacing the original, update that copy too.

The app header and Android 7 launcher icons display the original image. Android 8+
adaptive icons place it in the central 72 dp of the 108 dp layer, on white to match
the supplied image's border. Android applies the launcher's circle or rounded
square mask. The artwork's colors, arrow, and red mark are preserved.

The starter Android robot icons have been removed. No separate monochrome artwork
is supplied, so the adaptive icon does not opt in to Android 13 themed icons.

# Pilot findings template — no findings entered

**Status:** NOT CONDUCTED until genuine consenting participants are documented. Rehearsal exports must never be reported as human evidence. Fill placeholders only from actual consented observations; do not invent feedback or quotes.

1. **Participants:** actual count, study pseudonyms, voluntary relevant experience variation, incomplete/withdrawn sessions; no names/emails/sensitive demographics.
2. **Method:** consent/notes/recording permissions, browser/input environment, task order, facilitator interventions, synthetic fixture disclosure, retention/access.
3. **Tasks:** predefined scripts/criteria and fixtures used; explicitly identify any omitted/modified task.
4. **Technical issues:** observed failures, reproducible steps, environment, consequences; no private passages.
5. **Task results:** counts of success / success-with-help / failed / abandoned, participants needing help, wrong clicks/navigation errors. Use the latest final observation per participant/task for counts, retaining earlier attempts as context. Include denominators and missing tasks; no misleading averages/significance.
6. **Comprehension findings:** manually coded explanation accuracy; Skip/Cancel/Finish distinctions and optional support understanding.
7. **Navigation findings:** observed wrong actions, recovery and next-step uncertainty.
8. **Recommendation findings:** explanation clarity, Session focus, helpful/controlling perceptions and ordinary Practice preferences.
9. **Mastery-check findings:** actual comprehension/fairness comments; do not infer anxiety from typing performance.
10. **Exercise/content findings:** repeated themes about repetition, sentence/fragments, composition changes, length/difficulty and obvious target repetition; no efficacy claim.
11. **Accessibility findings:** actual methods/tools/participants, focus/keyboard/zoom/contrast observations; clearly state untested assistive technologies.
12. **Quotes/notes:** permission-confirmed pseudonymous short interface comments, reviewed for identifiers and passage content; otherwise leave blank.
13. **Severity-ranked usability issues:** issue ID, task, observed behavior, expected criterion, count/denominator, note/event references, severity and evidence strength. Critical blocks task/creates incorrect learning consequence; High frequent confusion/significant wrong action; Medium recoverable confusion; Low wording/polish. Separate from policy severity scores.
14. **Proposed changes:** precise UX fix, supporting observed issue, expected benefit, verification plan; identify uncertainty.
15. **Changes NOT justified by evidence:** threshold/policy recalibration, efficacy claims, scheduling, speculative redesign or isolated preference.
16. **Follow-up questions:** unresolved comprehension/content/accessibility themes, repeat pilot needs and separately scoped longitudinal evidence requirements.

**Interpretation statement:** This small qualitative study describes usability/workflow and immediate content perception. It does not establish that adaptive training improves typing skill. Keep usability changes separate from learning-policy calibration.

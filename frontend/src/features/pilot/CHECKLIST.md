# One-page facilitator checklist

**Before each session**

- [ ] Confirm voluntary participation consent and explain stopping/skipping.
- [ ] Assign P01–P99; collect no name, email, account or private text.
- [ ] Confirm separate note/quote permission and any audio/video/screen permission.
- [ ] Agree export access, retention and withdrawal/deletion handling.
- [ ] Choose correct provenance: rehearsal or genuine consented pilot.
- [ ] Reset only this participant’s study state; preserve unrelated accounts.
- [ ] Check browser, keyboard/focus, viewport/zoom and local export location.
- [ ] Confirm synthetic starting history is labelled; facilitator controls stay separate.
- [ ] Review task criteria and task order before observation.

**During**

- [ ] Read neutral prompts; do not name the expected control prematurely.
- [ ] Let the learner think aloud; wait before correcting.
- [ ] Record wrong clicks, help and explanation accuracy manually.
- [ ] Note confusion/content themes without inferring emotion from metrics.
- [ ] Label fixture loads; never count them as participant improvement.
- [ ] Avoid identifiers, credentials, raw passages/input in notes.
- [ ] Respect stopping or declined tasks; check local capture/capacity status.

**After**

- [ ] Conduct the short, nonleading interview.
- [ ] Review notes for privacy and confirm recorded pseudonym/provenance.
- [ ] Export local JSON explicitly; verify file/version before clearing.
- [ ] Clear this participant’s study data/reset environment as agreed.
- [ ] Store exports only under the agreed access/retention rules.
- [ ] Report descriptive counts/themes; no efficacy or threshold claims.
